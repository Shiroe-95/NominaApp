## Visión del Proyecto

**Nomina Smart** tiene como objetivo convertirse en una de las mejores aplicaciones de nómina del mercado, destacándose por su **alta confiabilidad**, **experiencia de usuario excepcional** y **eficiencia operativa**. Estamos construyendo una solución integral que no solo automatiza procesos, sino que transforma la manera en que las organizaciones gestionan su nómina.

### Objetivos Estratégicos

| Pilar | Descripción |
|-------|-------------|
| **Confiabilidad** | Cálculos precisos garantizados, auditoría continua y cumplimiento normativo al 100%. Cero errores en liquidaciones de salarios, deducciones fiscales y aportes. |
| **Usabilidad** | Interfaz intuitiva que reduce la curva de aprendizaje. Flujos de trabajo optimizados para que cualquier usuario pueda operar el sistema sin capacitación extensiva. |
| **Eficiencia** | Automatización inteligente que reduce tiempos de procesamiento de nómina de días a minutos. Eliminación de tareas manuales repetitivas. |
| **Escalabilidad** | Arquitectura diseñada para crecer desde PYMEs hasta grandes corporaciones con miles de empleados sin degradar el rendimiento. |

### Funcionalidades Core de Nómina

- **Gestión Integral de Empleados**: Administración completa de datos del personal incluyendo información contractual, histórico laboral, documentos y configuraciones individuales de pago.
- **Cálculo Automatizado de Salarios**: Motor de cálculo que procesa salarios base, horas extras, bonificaciones, comisiones y cualquier concepto salarial configurable.
- **Deducciones Fiscales y Parafiscales**: Cálculo automático de retención en la fuente, aportes a seguridad social (salud, pensión, ARL), parafiscales (SENA, ICBF, Caja de Compensación) y embargos judiciales.
- **Reportes y Analítica Avanzada**: Generación de reportes de nómina, certificados laborales, informes para entidades regulatorias y dashboards ejecutivos con métricas clave.
- **Actualizaciones en Tiempo Real**: Sincronización instantánea de cambios, notificaciones proactivas y visibilidad completa del estado de cada proceso.
- **Automatización Inteligente**: Flujos automatizados para liquidaciones periódicas, provisiones, cierre de mes y generación de archivos bancarios.

### Principios de Desarrollo

- **Seguridad First**: Encriptación de datos sensibles, control de acceso basado en roles (RBAC), logs de auditoría y cumplimiento de normativas de protección de datos.
- **Mantenibilidad**: Código limpio, modular y bien documentado siguiendo mejores prácticas de la industria.
- **Responsividad**: Experiencia fluida en cualquier dispositivo, desde desktop hasta móvil.
- **Integración Continua**: APIs robustas para conectar con ERPs, sistemas contables y plataformas bancarias.

## ¿Qué es Nomina Smart?

**Nomina Smart** revoluciona el proceso de gestión y auditoría salarial. Además de sus capacidades completas de nómina, realiza una verificación de **"Triple Match"**, cruzando inteligentemente información entre:

1. **Nómina Interna** (Archivos fuente extraídos desde tu ERP).
2. **Pago PILA** (Planilla Integrada de Liquidación de Aportes).
3. **Estándar UGPP** (Cálculo normativo oficial y regulatorio).

El sistema utiliza algoritmos impulsados por Inteligencia Artificial para inferir mapeos automáticos de datos atípicos, detectar inconsistencias críticas, calcular el **Nivel de Riesgo por Empleado**, sugerir reparaciones proactivas y gestionar hallazgos a través de un moderno panel colaborativo para equipos de Recursos Humanos y Auditoría.

El proyecto sigue una arquitectura modular y escalable, diseñada para facilitar el mantenimiento y la extensión de funcionalidades.

```
nomina-smart/
├── messages/                 # Diccionarios de internacionalización (es.json, en.json)
├── scripts/                  # Scripts de configuración y mantenimiento
├── src/
│   ├── app/
│   │   ├── [locale]/         # Rutas con soporte multilenguaje
│   │   │   ├── login/        # Autenticación de usuarios
│   │   │   ├── reconcile/    # Módulo de conciliación y validación
│   │   │   ├── reports/      # Reportes y analíticas
│   │   │   ├── rules/        # Configuración de reglas de negocio
│   │   │   ├── settings/     # Configuración del sistema
│   │   │   └── upload/       # Carga de archivos de nómina
│   │   └── api/              # Endpoints REST (nómina, reglas, IA)
│   ├── components/
│   │   ├── layout/           # Componentes de estructura (Header, Sidebar)
│   │   └── ui/               # Componentes reutilizables
│   ├── i18n/                 # Configuración de internacionalización
│   ├── lib/
│   │   ├── db/               # Esquemas y queries de base de datos
│   │   ├── payroll/          # Lógica de negocio de nómina
│   │   └── supabase/         # Clientes de Supabase (admin, server, client)
│   └── middleware.ts         # Middleware de autenticación y locale
├── package.json
└── tsconfig.json
```

## Guía de Inicio Rápido

### 1. Prerrequisitos
- **Node.js** V20+ y NPM instalados
- Cuenta en **Supabase** (para base de datos)
- API Keys de **OpenAI** y/o **Anthropic** (para funciones de IA)

### 2. Instalación

```bash
git clone https://github.com/Shiroe-95/NominaApp.git
cd NominaApp
npm install
```

### 3. Variables de Entorno

Configura tu archivo `.env.local`:

```ini
# Supabase
NEXT_PUBLIC_SUPABASE_URL=tu_supabase_url
NEXT_PUBLIC_SUPABASE_ANON_KEY=tu_supabase_anon_key
SUPABASE_SERVICE_ROLE_KEY=tu_supabase_service_role_key

# Inteligencia Artificial
OPENAI_API_KEY=tu_openai_api_key
ANTHROPIC_API_KEY=tu_anthropic_api_key
```

### 4. Ejecutar la Aplicación

**Desarrollo:**
```bash
npm run dev
# Disponible en http://localhost:3000
```

**Producción:**
```bash
npm run build
npm start
```

## Flujo de Trabajo

### Gestión de Nómina
1. **Configurar Empresa**: Registra los datos de la empresa y configura parámetros de nómina.
2. **Cargar Empleados**: Ingresa la información del personal o importa desde Excel.
3. **Procesar Nómina**: Ejecuta la liquidación y revisa los cálculos automáticos.
4. **Generar Reportes**: Descarga desprendibles, archivos bancarios y reportes regulatorios.

### Auditoría con IA
1. **Carga y Mapeo**: Sube archivos Excel desde `/upload`. La IA identifica automáticamente las columnas.
2. **Análisis Normativo**: El módulo **Reconciliador** verifica cumplimiento de la Ley 1393 y otras normativas.
3. **Gestión de Hallazgos**: Asigna, prioriza y cierra casos desde el panel de acciones.
4. **Monitoreo**: Visualiza el **Scoring de Salud de Nómina** en el Dashboard principal.
